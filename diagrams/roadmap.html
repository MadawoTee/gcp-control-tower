GCP learning lab · personal account

Learning Lab Roadmap

Six phases, built one at a time, each proven before the next starts. This reworks the enterprise control tower for a real personal account: no assumed Organization, a strict cost ceiling, and one environment until the fundamentals are solid. Full network topology detail lives in the companion Control Tower Blueprint.

Step 0 — a standalone project, no domain needed

Decision made: building without a domain for now. Every stage defaults folder_id and org_id to null, so 0-bootstrap creates a plain project with no Organization parent — exactly what you'd get creating one by hand in the console. The domain/Cloud Identity path stays available later, as an opt-in, not a prerequisite.

✓

This is what's actually built. 0-bootstrap and 1-networking are live in the repo, reusing the same modules/vpc-spoke and modules/firewall-baseline the enterprise design uses. The org-dependent stages moved to advanced/ — real, working Terraform, just set aside until their tickets (NET-5 onward) come up.

Networking: start simple, level up later

Phase 2 ships a single VPC — the fundamentals. Hub-and-spoke (already built in the control tower repo's modules/vpc-hub, vpc-spoke, ncc-hub-spoke) becomes a deliberate NET-5 ticket once that's solid, not the starting point.
