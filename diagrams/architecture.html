Control Tower Blueprint

How this repository's Terraform stages fit together: one Network Connectivity Center hub joining three per-environment Shared VPCs, a GKE cluster and AI workload dropped into each spoke, and a GitHub Actions pipeline that applies every stage through Workload Identity Federation — no service account keys, anywhere.

Network & compute topology

Every environment owns its own project and its own VPC. Network Connectivity Center gives every spoke a transitive route to every other spoke through the hub — dev can reach staging without a direct peering link between them.

networking / hub dev environment staging environment prod environment AI workload

CI/CD pipeline

GitHub Actions authenticates to GCP by exchanging a short-lived OIDC token for GCP credentials — Workload Identity Federation — so no service-account key ever leaves Google Cloud or sits in a GitHub secret.
